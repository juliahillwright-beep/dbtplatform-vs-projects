Available as add-ons for any dbt deployment

dbt Wizard

AI-powered CLI + Desktop App for local dbt development
Pay-as-you-go
  • AI-assisted dbt development in your local environment or terminal
  • Same Copilot capabilities as the platform — without a cloud subscription
  • Powered by dbt Fusion for real-time feedback and fast builds
  • Designed for the ~100K weekly active dbt Core users without a platform subscription
  • Platform customers can use it as a local alternative to the browser-based IDE
Available for: dbt Core users · dbt platform customers · All data platforms

dbt State

State-aware orchestration as a standalone add-on
Pricing scoped upon consumption
  • Automatically skips unchanged models across production runs and local development
  • Combines state-aware orchestration from the dbt platform with Fivetran's dbt State
  • Works across dbt Core (v1.7+), Mantle, and Fusion — locally and in external orchestrators
  • Platform customers on Enterprise/Enterprise+ already include SAO — dbt State extends this to Core users
  • Delivers ~30% average warehouse compute reduction (up to 50% reported)
Available for: dbt Core · dbt Starter · dbt Enterprise · dbt Enterprise+
